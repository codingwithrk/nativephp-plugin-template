# Contributing

Thank you for improving `{{ vendor }}/{{ package }}`.

## Development

```bash
composer install
composer test
composer lint
```

## Pull Requests

- Keep changes focused.
- Add or update tests when behavior changes.
- Update documentation when public usage changes.
- Keep placeholders intact unless the change intentionally updates the template contract.

## NativePHP Compatibility

Follow official NativePHP Mobile plugin conventions for `nativephp.json`, Android bridge functions, and iOS bridge functions.
